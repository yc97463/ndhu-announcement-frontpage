1. 讓專業的帶你去！國合會 ( TaiwanICDF ) 介紹
 
國際合作發展基金會(簡稱國合會)於 85 年正式設立，同年成立「海外服務工作團」，
派遣符合夥伴國家需求之海外志工，協助開發援助或人道援助專案執行，
28 年來累計派遣 861 名海外志工分赴非洲、中南美洲、亞太及加勒比海地區等 47 個友邦
及友好國家提供志願服務，協助派遣國家提升經濟及社會發展。

國合會在「大專青年海外技術協助服務計畫」架構下，
結合各大專院校開設之實習課程，辦理「海外服務工作團－大專青年實習志工專案」，
提供國內在學青年赴海外進行志願服務與學習，增進自身專業能力與實務經驗，
且培養獨立自主的精神，拓展國際視野，有助未來職涯發展。

2. 申請資格  
(1). 具中華民國國籍。
(2). 年齡 20 歲(含) 以上。
(3). 大學部或研究所在學生，服務期間 ( 114 年 8 月至 115 年 1 月 ) 需具有學籍
(4). 專業領域符合欲所申請之實習計畫所列條件

3. 派遣時間 ( 1 學期 )  
服務時間原則上為本年 8 月至隔年 1 月底。
(註：實際派遣時間可能依計畫期程等需求略為調整)

4. 提供生活津貼、住宿、赴離任機票，為實習志工投保 意外險及國際醫療險  
本項目之細節請洽本專案國合會聯絡人。
國合會窗口 人道援助處 呂先生
電話：02-2888-6058
電子郵件: i.l.lu@icdf.org.tw

5. 申請文件  

一、必要文件
➢ 實習申請表 ( 電腦繕打+列印簽名 )
➢ 大學歷年成績單中文版正本（含成績排名）
➢ 申請多媒體項目者，請提供影音、美編相關作品

二、其他有利於申請之文件
➢ 2 年內英語/其他外語能力證明
➢ 推薦信（由所屬系所教師或主管推薦）
➢ 志願服務相關證明文件
➢ 證照/檢定或相關訓練證明
